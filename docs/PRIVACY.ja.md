# Inari MCP for Firefox のプライバシーポリシー

[English](./PRIVACY.md) | **日本語**

最終更新日：2026-10-14

このポリシーは、Firefox の拡張機能「Inari MCP for Firefox」と、それと組んで手元の PC で動くこのリポジトリのプログラム（ネイティブホストと MCP サーバー）を対象にする。以下、まとめて「Inari MCP」と呼ぶ。

## 責任者

Inari MCP の開発者は GitHub のハンドル **elys0912**。連絡は [GitHub の Issues](https://github.com/elys0912/InariMCP/issues) だけで受け付ける。Issues は公開されるので、個人情報は書かないこと。

## 要点

- Inari MCP は、手元の PC で動くプログラム（Claude Code などの MCP クライアント）が、あなたの Firefox のタブを読んだり操作したりできるようにする。
- タブから読んだ内容は、同じ PC の MCP クライアントへ渡る。MCP クライアントは、それを自分が使う AI のサービスへ送る。
- 開発者には何も送らない。開発者はサーバーを持たず、データ・統計・クラッシュレポートのどれも受け取らない。
- ページやブラウザへの操作（クリック、入力、要素の上にマウスのポインタを置く、フォームの送信、ページの移動、タブを開く・閉じる）は、どのサイトでも毎回あなたの承認を待つ。読み取り・待機・タブの切り替えは承認を求めない。ただし、あなたが指定したサイトでは、ページの読み取りとスクリーンショットも承認を待つ。
- 拡張機能で撮ったスクリーンショットは手元の PC に 30 日残る。ツールの呼び出しの記録（時刻・ツール名・URL）も手元の PC に残る。どちらもいつでも消せる。

## 読み取って送るもの

Inari MCP がブラウザから何かを読むのは、MCP クライアントがツールを呼んだときだけで、読むのはそのツールに要る分だけ。ツールによって次のものを読む。

- **ページの文字と要素**：ページの本文と、リンク・ボタン・入力欄などの要素（タグ、文字、属性、位置、CSS セレクタ）。
- **フォームの値**：入力欄に今入っている値。次の欄の値は `[MASKED]` に置き換え、送らない：パスワードの欄、hidden の欄、ワンタイムコードの欄（`autocomplete="one-time-code"`）、クレジットカードの欄（`autocomplete` が `cc-` で始まるもの。`cc-number`・`cc-csc`・`cc-exp`・`cc-name` など）。
- 操作しているタブの **URL とタイトル**。
- **開いているタブの一覧**：各タブの URL・タイトル・コンテナ（既定は今のウィンドウの 50 件まで）。
- タブ・ページ全体・全タブの **スクリーンショット**。
- **Firefox のコンテナ**：ツールがコンテナを一覧したり、コンテナでタブを開いたりするときのコンテナの名前。

**cookie**：Inari MCP は cookie を読まず、cookie そのものも名前も値も送らない。`cookies` の権限は、タブがどの Firefox のコンテナにあるかを読むためと、コンテナでタブを開くためだけに要る。

ページの文字とスクリーンショットには、画面に出ているものが何でも入りうる。個人情報も含まれうる。伏せるのは上に挙げた欄だけで、伏せるのはツールがページから読む値だけ。スクリーンショットは画面の画像なので伏せない。欄に表示されている値（普通の文字の欄に入力したカード番号など）は、そのまま写る。

**通信の待ち**：ツールがページの通信が止むのを待つ間（`for: "network_idle"` の `fox_wait`）だけ、拡張機能はページ自身の `fetch` と `XMLHttpRequest` の `send` を包む。包んだ関数は、始まったリクエストと終わったリクエストを数えるだけ。呼び出しはそのままページの元の関数に渡し、リクエストの中身（URL、ヘッダ、本文、応答）は読まず、残さない。待ちが終わると元の関数に戻す。

Inari MCP は、あなた自身のブラウザ操作を記録せず、閲覧履歴も残さない。ツールの呼び出しが無ければ何も読まず、送らない。例外は、あなたが拡張の右クリックメニューやツールバーのポップアップを自分で使ったとき（「手元の PC に残るもの」を参照）。

## 送り先

1. **拡張機能**は、データを **ネイティブホスト** へ送る。ネイティブホストは、Firefox がネイティブメッセージングで起動する手元の PC のプログラム。
2. ネイティブホストは、それを同じ PC で動く **Inari MCP のサーバー（daemon）** へ渡す。daemon にはローカルのアドレス 127.0.0.1 からしか繋がらない。スクリーンショットは画像のまま渡さない。ネイティブホストがファイルに保存し、ファイルの場所だけを渡す。
3. daemon は、そのデータを、あなたが接続した **MCP クライアント**（例：Claude Code）へ返す。
4. MCP クライアントは、それを自分が使う **AI の提供元** へインターネット経由で送る。MCP クライアントがスクリーンショットのファイルを開けば、その画像も AI の提供元へ送られる。

拡張機能そのものはネットワークに接続しない。この経路に開発者のサーバーは入っていない（そもそも無い）。インターネットへ送るのは MCP クライアントで、Inari MCP ではない。MCP クライアントと AI の提供元がデータをどう扱うかは、それぞれのプライバシーポリシーで決まる。MCP クライアントを接続する前に、それを読むこと。

## 手元の PC に残るもの

すべてホームディレクトリの `.inari-mcp` フォルダ（`~/.inari-mcp/`）にある。

| ファイル・フォルダ | 中身 | 残る期間 |
|---|---|---|
| `screenshots/` | ツールや右クリックメニューで撮ったスクリーンショット | 名前にかかわらず 30 日で消す（ネイティブホストが起動するたびに確かめる）。日数は `FOX_SCREENSHOT_RETENTION_DAYS` で変えられる。ヘッドレスモード（`FOX_HEADLESS=1`。拡張機能を使わず、MCP サーバーが自分の Firefox を動かす）で撮ったスクリーンショットもここに保存するが、自動では消さない。自分で消すこと |
| `logs/audit.jsonl` | ツールの呼び出し 1 回につき 1 行：時刻、ツール名、URL、判定（許可・拒否・承認など）、呼び出しの引数。引数のうち、ページに入力する文字・フォームの値・パスワードは `***` に置き換える。ページの内容は書かない。`safety.json` で `"audit_log": false` にすると書かない | 5 MB を超えたら `audit.jsonl.old` に名前を変える（古いものは 1 つだけ残す） |
| `logs/daemon.log`、`logs/native-host.log` | プログラム自身のメッセージ：起動、停止、接続、コマンド名、エラー。ページの内容は書かない。エラーのメッセージにツール名や URL が入ることはある | 上と同じ（5 MB、古いもの 1 つ） |
| `safety.json`、`api_token` | 設定と、手元のプログラムどうしが互いを確かめるための鍵 | 消すまで |

ツールバーのポップアップの 2 つのボタンは、押したときだけ、このフォルダの外に残す。「スクリーンショット」は今のタブの画像を Firefox のダウンロードのフォルダに保存し、「ページ情報」は今のページの情報（URL、タイトル、見出し、リンク・ボタン・入力欄とその値。値は上と同じく伏せる）をクリップボードにコピーする。Inari MCP はどちらも消さない。これらのほかに、拡張機能は、ページの内容・スクリーンショット・URL を Firefox の中に保存しない。

## 消し方

- ネイティブホストと上のデータをまとめて消す：Inari MCP を入れたフォルダで `npm run teardown -- --purge` を実行する。
- または `~/.inari-mcp/` フォルダを自分で消す（先に Firefox と MCP クライアントを終了する）。
- Firefox から拡張機能を外す：`about:addons` → Inari MCP for Firefox → 削除。

MCP クライアントや AI の提供元がすでに受け取ったデータは、Inari MCP の外にある。消すときはそれぞれの方法で消す。

## 同意と制御

- **許可の画面**：拡張機能が初めて起動したとき、許可を求める画面を開く。画面には、拡張機能の名前、何をどこへ送るか、ネイティブホストが要ることを書いてある。そこで許可するまで、拡張機能はネイティブホストに繋がず、何も送らない。拒否すれば繋がないままになる。ツールバーのポップアップには、この画面を開き直すリンクが常にあり、そこで答えを変えられる。「許可しない」を押すと、拡張機能はその場で接続を切る。
- **操作の承認**：ページやブラウザへの操作は、どのサイトでも毎回、あなたが承認するまで待つ。対象は、クリック、入力、キーの入力、入力欄の値の設定、要素の上にマウスのポインタを置く操作（hover）、ページの移動、タブを開く・閉じる操作。承認は MCP クライアントの確認ダイアログか、拡張機能のツールバーのポップアップで行う。ページの中からは承認できない。1 回の承認が効くのは、1 つのサイトでの 1 回の呼び出しだけ。サイトはページのホスト名で、ローカルのファイルと空のタブではスキーム（`file:`、`about:`）になる。タブがどのページにあるかを Inari MCP がまだ知らないときは、タブの一覧を読み直す（`fox_tabs`）まで、そのタブでの操作は承認できない。ページやタブの一覧を読む、スクリーンショットを撮る、待つ、タブを切り替える、スクロールする、要素を強調表示する、の各操作は承認を求めない。ただし `~/.inari-mcp/safety.json` の `confirm_read_sites`（既定は空）に書いたサイトでは、ページの読み取りとスクリーンショットも承認を待つ。
- **MCP クライアントでの承認**：MCP クライアントの確認ダイアログ（MCP elicitation。既定で有効）での回答は、ローカルのアドレス 127.0.0.1 を通り、`~/.inari-mcp/api_token` の鍵で認証されて Inari MCP のサーバーに届く。そのため、このファイルを読める手元の PC のプログラム（あなたのユーザーアカウントで動くプログラムなど）は、自分の要求を自分で承認できる。ツールバーのポップアップでだけ承認するには、MCP クライアントと Firefox の環境に `FOX_APPROVAL_ELICITATION=0` を設定する。
- **バッジ**：ツールがブラウザを操作している間、ツールバーのボタンにバッジが付く。
- **一時停止**：ツールバーのポップアップに一時停止のスイッチがある。止めている間は、ツールの呼び出しをすべて断る。実行中の呼び出しも中断する。
- **無効化と削除**：`about:addons` で拡張機能を無効にすると、ブラウザへの操作はすべてその場で止まる。削除して上の手順を行えば、Inari MCP は無くなる。

## プライベートブラウジング

Inari MCP はプライベートウィンドウでは動かない。拡張機能は「プライベートウィンドウでの実行を許可しない」としてあるので、Firefox はプライベートのタブを拡張機能に見せず、操作もさせない。プライベートブラウジングの内容は読まず、残さない。

## 子どもの利用

Inari MCP は、自分の PC で AI のツールを使う大人のための道具で、子ども向けではない。開発者は、子どもを含め誰のデータも集めない。
