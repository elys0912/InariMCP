Allow Inari MCP for Firefox to connect?

What it does

It lets an MCP client on this computer (such as Claude Code) operate Firefox: read pages, take screenshots, click, type and manage tabs.

What it sends

The content of open pages (including the values of form fields; password and similar fields are masked), screenshots, URLs, the list of tabs and the names of your containers. They go to the native host on this computer and from there to the MCP client, which may pass them on to its AI provider.

What you need

The Inari MCP native host, installed separately on this computer (see the installation guide).

If you do not allow it

The add-on does not connect to the native host and does nothing. You can allow it later from the toolbar button.
