Allow Inari MCP for Firefox to connect?

What it does

It lets an MCP client on this computer (such as Claude Code) operate Firefox: read pages, take screenshots, click, type and manage tabs.

What it sends

The content of open pages, screenshots, URLs and the list of tabs, through the native host on this computer to the MCP client. The MCP client may pass them on to its AI provider.

What you need

The InariMCP native host, installed separately on this computer (see the installation guide).

If you do not allow it

The add-on does not connect to the native host and does nothing. You can allow it later from the toolbar button.
